# TtA Challenge Highscores

Domination leaderboard for the Through the Ages app challenges. One Cloudflare Worker (Preact SPA + `/api`) and a
D1 database, on the free plan. Live: https://tta-challenges.olesch.workers.dev. README.md has the full overview.

## Commands

- `npm run dev` — local site on http://localhost:5173 with a local D1 (`npm run db:migrate:local` and
  `npm run db:import:local` fill it). `.claude/launch.json` config `tta-dev` starts it in the preview pane.
- `npm run typecheck` — must pass before deploying.
- `deploy.bat` / `npm run deploy` — the owner has authorized deploys and commits in this project.
- Windows: the Bash tool's `npm` may be missing from PATH; `C:/Program Files/nodejs/node.exe` works. Python with
  openpyxl/pyyaml/pillow is `/c/Python313/python.exe`.

## Layout

- `src/worker/` server: `index.ts` (API, admin routes, rate limit, 30 s entry cache), `preview.ts` (Discord/Open Graph tags).
- `src/app/` browser app: `data.ts` computes all stats client-side from GET /api/entries; `pages/` one file per page.
- `src/shared/` used by both: challenge list, validation rules, API types.
- `migrations/` numbered D1 schema changes; add a new file, never edit an applied one.
- `data/`, `seed/`, `public/img/` are generated by `tools/` from the game files and the old Google Sheet.

## Rules that are easy to break

- Wording: say "domination" (final score minus second place), never "score", in anything users see. English only, English dates.
- Bugged entries never count anywhere; negative dominations count as 0 in sums, pooled totals and ratings (`countedScore`).
- Verified = has a Discord message link from guild 358698681672925195.
- Never run `npm run db:import:remote` (replaces live data; guarded by a typed phrase). Take
  `npm run db:backup:remote` before any remote migration or bulk change.
- No third-party requests from the site (fonts are self-hosted for GDPR). No cookies or tracking.
- `src/app/pages/Privacy.tsx` is an unpublished draft with `[NAME]`/`[EMAIL]` placeholders; don't wire it in
  until the owner supplies them.
- Never print or commit `ADMIN_TOKEN`; `.dev.vars` (local test password) stays uncommitted.
